
# API Backend Cloud

Proyecto académico de Algoritmos Paralelos.

## Tecnologías

### Backend
- Java
- Spring Boot
- Spring Security
- JWT
- PostgreSQL

### Mobile
- Flutter
- Dart

### Cloud e infraestructura
- AWS Lambda
- Amazon API Gateway
- Neon PostgreSQL
- Terraform
- GitHub Actions

## Estructura

- backend/: API REST desarrollada con Spring Boot.
- mobile/: Aplicación móvil desarrollada con Flutter.

## Objetivo

Desplegar una API REST en AWS Lambda,
conectada a PostgreSQL en Neon,
y automatizar su despliegue mediante GitHub Actions.
